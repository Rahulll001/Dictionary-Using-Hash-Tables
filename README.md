
# Dictionary Application Using Hash Tables

## 1. Introduction
This project implements a simple dictionary using
a hash table to store words and their meanings.

## 2. Objective
To insert, search, and display words and meanings
using hashing.

## 3. Data Structure
Hash Table

## 4. Collision Resolution
Linear Probing

## 5. Algorithm
1. Calculate a hash index for each word.
2. Store the word and meaning at that index.
3. If the position is occupied, check the next position.
4. Search for words using the same hash function.
5. Display all stored words and meanings.

## 6. Features
- Add words and meanings.
- Search for a word.
- Update an existing meaning.
- Display dictionary contents.
- Resolve collisions using linear probing.

## 7. Time Complexity
Average insertion and search: O(1)
Worst-case insertion and search: O(n)

## 8. Conclusion
Hash tables provide fast word retrieval.
Linear probing handles collisions when multiple
words map to the same index.
